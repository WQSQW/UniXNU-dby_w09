# Proprietary inputs of the Huawei MatePad 11 (dby_w09) port.

# They stay out of Git. `unixnu ipsw fetch` extracts the members named by board.toml [ipsw] fetch
# from the pinned iPad7,1 iPadOS 17.7.11 (21H461) restore image, and the build tree links the
# device repository's .cache/firmware directory (scripts/unixnu/tree.py), so every tree and every
# rebuild reads the same files without copying them into this repository.
#
# path|sha256    file relative to .cache/firmware
# -path|sha256   optional file: a missing one is reported, not an error
#
# Provenance of every file below is Apple's restore image, except the touch entries at the end, which come from this
# model's own stock package (see @fetch/SECTION notes there). The claim this file used to carry - that the port needs no
# vendor firmware at all - was written before the touch bring-up reached stage 4 and is wrong: the controller's
# command mailbox, its firmware image and the panel's AFE decoding library are vendor files, and the official input
# record (core/docs/porting/input.md) names the firmware object as a stage-4 requirement.

# Touch (Huawei THP, Novatek N9Z series: huawei_thp@10 support_vendor_ic_type = <0x05>, b01.dts:10083).
#
# SOURCE is a directory holding this model's stock system as unpacked from its super image, so the official route
# applies unchanged:  python3 scripts/extract-files.py <stock-package-dir> --section Touch
#
# There is no standalone TP firmware file in that package: the image runs from the panel's own flash (the novatech
# child sets project_in_tp = <0x00>, b01.dts:10115, and the vendor's THP driver has no download path at all - only
# the STATUS_CMD/gesture/sleep commands of novatek_thp.c:975-1160), so gen-touch-firmware.py has no blob to embed and
# emits size 0. What the port really needs from this package is the other half of the protocol: the kernel hands the
# 8208-byte burst to userspace untouched (huawei_thp_core.c:3807 -> :3575) and the closed AFE library is the only
# thing that has ever decoded it. Those files are reference inputs for this port's decoder - they stay out of Git and
# never go into an image. Digests are of the files as shipped in that package; extract-files.py refuses a mismatch.
#
# Touch
