# Proprietary inputs of the Huawei MatePad 11 (dby_w09) port.

# They stay out of Git. `unixnu ipsw fetch` extracts the members named by board.toml [ipsw] fetch
# from the pinned iPad7,1 iPadOS 17.7.11 (21H461) restore image, and the build tree links the
# device repository's .cache/firmware directory (scripts/unixnu/tree.py), so every tree and every
# rebuild reads the same files without copying them into this repository.
#
# path|sha256    file relative to .cache/firmware
# -path|sha256   optional file: a missing one is reported, not an error
#
# Provenance of every file below is Apple's restore image. No vendor firmware is required by this
# port: there is no touch controller firmware, no Adreno ZAP firmware and no modem or DSP blob,
# because input and GPU are not ported yet.

# KernelCache member, decompressed from kernelcache.im4p. The prelinker reads its original
# __TEXT_EXEC extents and instruction hashes; kits/XnuPrelink and scripts/*.py refuse any change.

# StaticTrustCache member, taken as the unmodified original bundle. scripts/build-original-system-
# trust.py pairs it with Cryptex1,SystemTrustCache from the same build; the resulting bundle hash
# is the first pin of board.toml [payload] trust_cache_sha256.
target-volumes/static-trustcache.bin|da88460e6e513438d5307e5c526f76497a74754476a24da29f239f0c90120fc2
